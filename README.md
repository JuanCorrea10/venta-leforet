# Venta · Leforet El Vergel · Apto 1605

Sitio web one-page para la venta del apartamento 1605 del edificio Leforet El Vergel, en Ibagué (Tolima, Colombia).

## Vista previa

> Próximamente: link al sitio en vivo via Netlify.

## Sobre el proyecto

- **Apartamento esquinero** de 167,45 m², piso 16
- 3 habitaciones · 2,5 baños · 2 balcones · 1 garaje · 1 depósito
- Vista doble: montaña en zona social, ciudad en habitaciones
- Estrato 6 · Sector El Vergel, Ibagué

## Stack técnico

- HTML5 semántico
- CSS3 moderno (custom properties, grid, scroll-driven animations)
- Tipografía: [Fraunces](https://fonts.google.com/specimen/Fraunces) + [Manrope](https://fonts.google.com/specimen/Manrope)
- Cero JavaScript todavía (próxima fase)
- Cero dependencias externas — solo HTML/CSS plano
